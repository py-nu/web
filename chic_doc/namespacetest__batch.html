Detailed Description

test_batch_plots.py — plotting smoke test for the batched CHIC bindings.

Exercises both:
  - pychic.CHIC_BATCH            (constant-density oscillations)
  - pychic_earth.CHIC_EARTH_BATCH (Earth-propagation oscillations)

For each, it computes oscillation weights (and, for CHIC_BATCH, a parameter
derivative) over a batch of events and plots the result, as both a
correctness check and a usage example of the batched API.

Run with:
    python test_batch_plots.py

Produces:
    chic_batch_test.png         — P(nu_mu -> nu_mu) vs baseline, plus
                                   dP/d(theta_23), at fixed energy.
    chic_earth_batch_test.png   — P(nu_mu -> nu_mu) oscillogram over
                                   (cos_zenith, energy) through the Earth.

◆ test_chic()

test_batch.test_chic ( ) 
Non-batched analog of test_chic_batch(): loops over baselines calling
CHICDIFF.compute_oscillations()/compute_oscillations_derivatives() one
event at a time, and overlays the result on the batched curve as a
cross-check that the two APIs agree.

Uses mode="antineutrino" to match what CHIC_BATCH actually dispatches to
for flavor=NU_MU=14 (see the NU_MU comment above) so the two curves are
directly comparable.

test_batch.test_chic_earth ( ) 
Non-batched analog of test_chic_earth_batch(): loops over the
(energy, cos_zenith) grid calling CHICEARTHDIFF.compute_oscillations()
one event at a time. Uses a coarser grid than the batched version since
the per-point Earth-layer setup is comparatively expensive. Plots the
direct oscillogram alongside the batched one and their difference, as a
cross-check that the two APIs agree.
